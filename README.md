# 💰 Finance Tracker

A modern AI-powered personal finance tracker built with Next.js, FastAPI, and Supabase.

---

- [x] Categories
- [x] Accounts
- [ ] Dashboard & Analytics
- [ ] Smart AI Categorization
- [x] Authentication
- [ ] Deployment
- [ ] Open Banking Integration
